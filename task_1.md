# Баги найденные на скриншоте

## P0 - Критический

## P1 - Высокий

- P1 - Не работает фильтр по цене при поиске объявлений (В выборку попали объявления за 500 рублей и 40000 рублей, хотя фильтр стоит от 1000 рублей до 30000 рублей)
- P1 - Не работает фильтр по региону поиска при поиске объявлений (В выборку попало объявление из Новосибирска, хотя геолокация указана Москва)
- P1 - Не работает фильтр по породе при поиске объявлений (В выборку попало объявление "Экзотический короткошёрстный котёнок", хотя поиск выполняется по породе "Персидская")
- P1 - объявление "Персидский котенок плюшевый" находится в неверной категории
- P1 - Некорректное наименование слайдера над плитками объявлений (Поиск производился по Москве, а в слайдере указано "сначала из Можайска")
- P1 - В правой части скриншота над плитками объявлений отображается сообщение "Ошибка, обновите страницу" (Может иметь приоритет P2, необходимо разбираться у какого количества пользователей возникает)
- P1 - не работает фильтр по полу при поиске объявлений (в фильтре указано "Мальчик", в выборке объявлений отображается объявление "Персидский котенок девочка")

## P2 - Средний

- P2 - Подсказка для кнопки "сердечко" содержит некорректное сообщение (на скриншоте отображается "Не показывайте мне похожие объявления", должно быть "Добавить в избранное и в сравнение")
- P2 - некорректный порядок хлебных крошек в пагинации категорий (на скриншоте "... -> Персидская -> Кошки", должно быть "... -> Кошки -> Персидская")
- P2 - Ошибка в терминологии в фильтре "Возраст" (на скриншоте "Щенок", должно быть "Котенок")
- P2 - отсутствует фильтр "Окрас" между фильтрами "Возраст" и "Пол" (Если сравнивать с продуктовой версией сайта Авито, так как отсутствие ничего не ломает)
- P2 - Фото не соответствует объявлению (В одном из объявлений на фото представлен бенгальский котенок)
- P2 - расхождение чисел заголовка выдачи объявлений и кнопки "Показать 8 объявлений" (Может быть и P1, если пользователи не видят из-за этого все объявления)

## P3 - Низкий

- P3 - Опечатка в кнопке "Карьера в Авито" в header страницы (На скриншоте "Коръера в Авито", должно быть "Карьера в Авито")
- P3 - Опечатка в кнопке "Уведомлять о новых" в правой части страницы над плитками объявлений (На скриншоте "Уведомять о новых", должно быть "Уведомлять о новых")
